# Licensing and third-party components

The browser editor and adapted headless runtime derive from **ntsc-rs-web (GPL-3.0-or-later)**. The full GPL license appears at the repository root in `LICENSE`.

Other bundled/source components have their own terms:

- `ntsc-rs` processing engine: MIT / ISC / Apache-2.0 options, per its pinned upstream source.
- `ntsc-rs-web-wrapper`: `LICENSE_MIT` and `LICENSE_APACHE`.
- `valadaptive-lib` Git submodule: CC0, see its `LICENSE` at the pinned revision.
- FFmpeg-derived AAC codec: follow the LGPL and any applicable FFmpeg/codec terms in `aac-codec/FFmpeg`, its `COPYING.*` files, and the `aac-codec` patches/configuration. The source uses a prebuilt AAC WASM artifact.
- Original upstream editor font files: refer to `src/assets/fonts/LICENSE.txt`.
- JavaScript/Rust dependency license inventories are generated by the package-build process.

Upstream's credits metadata have an LGPL version-label/text discrepancy; both relevant license texts and the pinned codec build configuration must be retained and assessed during release verification. Do not assume the generated inventory alone establishes compliance.

**Public browser deployment:** The accessible source offered for the actual distributed JS/WASM must include the modifications and code necessary to build and install it, including converter-specific Astro integration. The exact combined-work boundary still needs review before release; publishing this project does not automatically make unrelated independently developed website pages part of the converter. Do not use a link to a private repository as the public source offer.
